## Quiénes somos

Somos **Moon Studios**, un estudio creativo que construye productos digitales con identidad propia. Combinamos diseño minimalista con ingeniería sólida: desde la idea y el diseño hasta el despliegue y el soporte.

> *Un estudio. Todo un universo.*

---

## Qué hacemos

| Servicio | Qué incluye | Tecnologías |
|---|---|---|
| **Desarrollo web** | Sitios corporativos, landing pages, portales de clientes y dashboards | React · TypeScript · Vite · Tailwind |
| **Aplicaciones** | Apps de escritorio para Windows y apps móviles para Android | Tauri (Rust) · Capacitor |
| **Bots de Discord** | Bots a medida con comandos, música, moderación, economía y eventos | Node.js · Discord.js |
| **Plataformas a medida** | Eventos con entradas QR, educación en línea, votaciones y videoconferencias | Firebase · Supabase · LiveKit |

## Universo Moon

Nuestros propios productos, en producción:

| Proyecto | Qué es | Enlace |
|---|---|---|
| **Moon Studios Dashboard** | El espacio de trabajo del equipo: proyectos, tareas, trámites, conferencias y gestión. Versión web y app para Windows con actualizaciones automáticas. | [Abrir](https://moon-studios-dashboard.netlify.app) |
| **Moon Studios para Android** | Agenda, salas de video, tareas, trámites y tarjeta virtual con QR, con notificaciones al instante. | — |

| **MOON FEST** | Encuentros de Moon Studios con inscripción, entradas QR y control de acceso. | [Visitar](https://moon-studios-fest.netlify.app) |
| **Moon Academy** | Plataforma educativa con cursos, clases y proyectos de programación. | [Visitar](https://moon-academy-studios.netlify.app) |
| **Elecciones Moon Studios** | Procesos electorales con participación autorizada y resultados en vivo. | [Visitar](https://moonstudios-elecciones.netlify.app) |
